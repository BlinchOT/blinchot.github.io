# Лабораторная работа №10: Разработка ML-сервиса для предсказания одобрения ипотеки

## Цель работы

Освоить полный цикл разработки ML-сервиса: от обучения модели до создания API и веб-интерфейса.

## Описание задачи

Разработан консультирующий сервис, который предсказывает вероятность одобрения ипотеки на основе данных клиента. Сервис реализован на FastAPI и включает три эндпоинта:

- `POST /upload-model` — загрузка обученной модели в формате `.pkl`.
- `POST /predict` — предсказание по JSON-запросу.
- `POST /predict-from-csv` — предсказание по загруженному CSV-файлу.

## Используемые данные

Датасет содержит информацию о клиентах: возраст, пол, доход, кредитная история, сумма и цель кредита и другие признаки. Целевая переменная — `loan_status` (1 — одобрено, 0 — отказано).

## Обучение модели

Были обучены и сравнены две модели:
- Логистическая регрессия (ROC-AUC = 0.9483)
- Случайный лес (ROC-AUC = 0.9735)

Лучшая модель (случайный лес) сохранена и используется в сервисе.

## API и интерфейс

Реализован веб-интерфейс для ручного ввода данных и получения предсказания. Доступен по адресу `/` при запуске сервера.
