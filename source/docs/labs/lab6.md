# Лабораторная работа №6: Очистка и трансформация данных (pandas)

## Введение

Данная работа посвящена предобработке реальных данных с использованием библиотеки pandas. На примере датасета Titanic отрабатываются навыки очистки, трансформации и агрегации данных — ключевые этапы анализа перед построением моделей машинного обучения.

## Цель работы

Освоить методы очистки и трансформации данных с использованием библиотеки pandas на примере реальных данных из Kaggle.

## Описание набора данных

Использован классический датасет Titanic, содержащий информацию о пассажирах корабля.

### Тестовая выборка (test.csv)

### Основные признаки
- PassengerId — идентификатор пассажира
- Survived — выжил ли пассажир (0 = нет; 1 = да)
- Pclass — класс билета
- Name — имя
- Sex — пол
- Age — возраст
- SibSp — количество братьев/сестер/супругов на борту
- Parch — количество родителей/детей на борту
- Ticket — номер билета
- Fare — стоимость билета
- Cabin — номер каюты
- Embarked — порт посадки

## Трансформация данных

### Созданные признаки

| Признак | Описание | Пример |
|---------|----------|--------|
| Age_group | Категории возраста | Adult, Child, Teen |
| Title | Обращение из имени | Mr, Mrs, Miss, Master |
| Sex_binary | Пол в числовом формате | 0 (male), 1 (female) |
| FamilySize | SibSp + Parch + 1 | 1, 2, 3, ... |
| IsAlone | Один ли пассажир | 0/1 |
| Cabin_letter | Первая буква каюты | A, B, C, ... или Unknown |

**Примеры титулов:**
- Mr: 517 пассажиров
- Miss: 182 пассажира
- Mrs: 125 пассажиров
- Master: 40 пассажиров
- Dr: 7 пассажиров
- Rev: 6 пассажиров

### Преобразования типов

**Pclass (числовой → категориальный):**
- 1 → F (First)
- 2 → S (Second)
- 3 → T (Third)

**Sex (текстовый → числовой):**
- male → 0
- female → 1
