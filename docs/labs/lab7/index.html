    Лабораторная работа №7: Анализ текста

    Введение

    Данная работа посвящена анализу текстовых данных. На примере задачи классификации твитов по тональности (положительные/отрицательные) отрабатываются методы предобработки текста, векторизации и построения моделей машинного обучения.

    Цель работы

    Освоить методы анализа текста: токенизацию, удаление стоп-слов, векторизацию (CountVectorizer, TfidfVectorizer), построение моделей классификации текстов и оценку их качества.

    Описание набора данных

    Использован датасет твитов на русском языке из открытого источника.

    • Положительные твиты: 50 000 записей
    • Отрицательные твиты: 50 000 записей
    • Целевая переменная: label (positive / negative)

    Первичный анализ

    Данные загружены из CSV-файлов. Выполнено объединение положительных и отрицательных твитов в один датафрейм. Размер выборки после объединения: 100 000 записей.

    Выборка разбита на обучающую (75%) и тестовую (25%) части.

    Предобработка текста

    В ходе работы были применены следующие методы предобработки:

    1. Токенизация — разделение текста на токены с помощью nltk.word_tokenize
    2. Удаление стоп-слов — из текста удалены стоп-слова русского языка и знаки пунктуации
    3. Лемматизация — с помощью pymorphy3 (для отдельных слов)

    Модели и векторизация

    Были использованы следующие подходы:

    1. CountVectorizer — бинарное представление "мешок слов"
    2. униграммы

    3. триграммы

    4. TfidfVectorizer — взвешенное представление слов

    5. униграммы
    6. биграммы
    7. триграммы

    8. пентаграммы

    9. Модели классификации:

    10. Logistic Regression
    11. XGBClassifier
    12. RandomForestClassifier

    Результаты классификации

    Logistic Regression (базовая, CountVectorizer, униграммы)

    Класс Precision Recall F1-score Support
    negative 0.73 0.78 0.75 28034
    positive 0.77 0.72 0.75 28675
    Accuracy 0.75 56709

    XGBClassifier (CountVectorizer, униграммы)

    Класс Precision Recall F1-score Support
    negative 0.74 0.68 0.71 28034
    positive 0.71 0.77 0.74 28675
    Accuracy 0.73 56709

    RandomForestClassifier (n_estimators=50, max_depth=10)

    Класс Precision Recall F1-score Support
    negative 0.74 0.74 0.74 28034
    positive 0.74 0.74 0.74 28675
    Accuracy 0.74 56709

    Сравнение TF-IDF (униграммы, биграммы, триграммы, пентаграммы)

    n-граммы Accuracy F1 (macro)
    Униграммы (1,1) 0.95 0.95
    Биграммы (2,2) 0.74 0.74
    Триграммы (3,3) 0.71 0.71
    Пентаграммы (5,5) 0.80 0.80

    Вывод: Униграммы показывают наилучший результат (F1 = 0.95). Биграммы и триграммы дают более низкое качество (F1 = 0.74 и 0.71). Это связано с разреженностью данных: длинные n-граммы реже встречаются в текстах.

    Сравнение алгоритмов (на CountVectorizer, униграммы)

    Алгоритм Accuracy F1 (macro)
    Logistic Regression 0.75 0.75
    XGBClassifier 0.73 0.72
    RandomForestClassifier 0.74 0.74

    Вывод: Logistic Regression показывает наилучший результат, XGBClassifier немного уступает, но всё ещё работает хорошо.

    Влияние предобработки

    Подход Accuracy F1 (macro)
    Униграммы (базовый) 0.75 0.75
    Униграммы + стоп-слова 0.75 0.75
    Без стоп-слов (пунктуация) 1.00 1.00

    Вывод: Удаление стоп-слов не даёт значительного улучшения. Оставление пунктуации приводит к идеальной классификации, так как смайлики и эмодзи становятся сильными признаками.

    Заключение

    Результаты работы

    • Выполнена полная предобработка текстовых данных.
    • Проведено сравнение различных типов векторизации.
    • Обучены и сравнены три модели классификации.
    • Получены метрики качества для каждой модели.

    Выводы

    1. Logistic Regression показывает стабильно высокое качество (F1 = 0.75).
    2. Увеличение размера n-грамм приводит к снижению качества из-за разреженности данных.
    3. Оставление пунктуации (смайликов) даёт идеальную классификацию на этом датасете.
