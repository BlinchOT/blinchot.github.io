    Лабораторная работа №6: Очистка и трансформация данных (pandas)

    Введение

    Данная работа посвящена предобработке реальных данных с использованием библиотеки pandas. На примере датасета Titanic отрабатываются навыки очистки, трансформации и агрегации данных — ключевые этапы анализа перед построением моделей машинного обучения.

    Цель работы

    Освоить методы очистки и трансформации данных с использованием библиотеки pandas на примере реальных данных из Kaggle.

    Описание набора данных

    Использован классический датасет Titanic, содержащий информацию о пассажирах корабля.

    Обучающая выборка (train.csv): - Количество записей: 891 - Количество признаков: 12 - Целевая переменная: Survived (0 — погиб, 1 — выжил)

    Тестовая выборка (test.csv): - Количество записей: 418 - Количество признаков: 11

    Основные признаки: - PassengerId — идентификатор пассажира - Survived — выжил ли пассажир (0 = нет; 1 = да) - Pclass — класс билета - Name — имя - Sex — пол - Age — возраст - SibSp — количество братьев/сестер/супругов на борту - Parch — количество родителей/детей на борту - Ticket — номер билета - Fare — стоимость билета - Cabin — номер каюты - Embarked — порт посадки

    3. Sex_binary и IsAlone имеют умеренную отрицательную корреляцию (-0.30) — мужчины чаще путешествовали одни.
    4. Остальные корреляции слабые, что говорит о том, что признаки не дублируют друг друга.

    1. Наибольшее влияние на выживание оказывают класс, пол и возраст.
